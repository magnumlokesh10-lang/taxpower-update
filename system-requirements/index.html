TaxPower system requirements

TaxPower is desktop software for Windows. This page lists what you need before installing it, so that your trial or purchase starts smoothly.

The basics

ItemWhat you need
Operating systemWindows desktop. Windows 10 or Windows 11 is the usual choice. For server setups, ask us which version fits your case.
InternetNeeded for activation, updates, GST portal and Income Tax portal filing, TRACES downloads and e-invoice or e-way bill generation.
DatabaseTaxPower TDS stores its data in a PostgreSQL database that is set up during installation. We help you with this step.
AuthenticationEVC/OTP or a Digital Signature Certificate (DSC), depending on the filing you are doing. Keep your DSC token and its driver ready.
EmailNeeded if you want to email Form 16/16A certificates and reports directly from the software.
HardwareNeeds depend on how much data you handle and how many users work at the same time. Call us with your number of clients and users and we will advise.

One computer or many

TaxPower can run on a single computer. For an office with several users, multi-user access over a local network (LAN) is available at an additional charge. If you want to work from more than one location, speak to us before you buy so that the right setup is chosen.

What to keep ready for installation

  • Administrator access to the Windows computer
  • Your product key (for purchased licences) or the details you gave when you requested the trial
  • Portal logins for the GST or Income Tax accounts you will file from
  • DSC token and driver, if you file with DSC
  • A stable internet connection for the first-time setup

Frequently asked questions

Answers to questions that customers ask most often.

Is TaxPower cloud software?

No. TaxPower is a desktop application for Windows. It connects to the GST and Income Tax portals for filing and downloads.

Will it run on Mac?

TaxPower is built for Windows. Ask us if you want to know the options for running Windows on your computer.
