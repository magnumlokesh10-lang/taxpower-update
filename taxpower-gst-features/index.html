Returns & filing

Sales, summary, annual, composition and refund returns

Sales returns: GSTR-1 and IFF

Prepare outward supply returns from your own records or imported data.

Entering sales

  • B2B, B2C large and B2C small supplies
  • Exports, SEZ and deemed exports
  • Credit and debit notes and amendments
  • Nil-rated, exempt and non-GST supplies
  • HSN summary and documents issued
  • E-commerce supplies
  • Manual entry with GSTIN checks

Bringing data in

  • Excel and JSON files
  • Tally data
  • E-invoice and e-way bill data

Checking and filing

  • Download portal data and compare it with yours
  • Generate the JSON file and a draft PDF
  • File with EVC/OTP or DSC
  • Reset or delete portal data when needed
  • Move invoices of inactive or cancelled GSTINs
  • Compare GSTR-1 with GSTR-3B and PMT-06
  • GSTR-1A summary and PDF or Excel export

Monthly and quarterly summary: GSTR-3B

Build the summary return from your sales and purchase data and file it.

Preparing the return

  • Section-wise entry for tables 3.1, 3.1.1, 3.2, 4, 5, 5.1 and 6.1
  • Fill from Excel, JSON or by hand
  • Auto-fill from GSTR-1
  • ITC worked out from GSTR-2B with a claim summary

Reviewing

  • Compare with the portal return, GSTR-1, 2A and 2B
  • Set off tax from the cash and credit ledgers
  • Interest and liability breakup
  • Challan details for QRMP taxpayers

Filing

  • Validate, create the JSON and file online
  • Draft and system-generated PDFs
  • Reports in PDF or Excel

Yearly returns: GSTR-9, 9A and 9C

Prepare the annual return and the reconciliation statement without starting from scratch.

GSTR-9

  • Auto-populated from the year’s returns
  • Table 8A analysis and HSN summary
  • Table 7H reversals
  • Excel and JSON import
  • Comparison with source data
  • Draft PDF and online filing

GSTR-9A

  • Prepare from Excel, JSON, the portal or by hand
  • Download from the portal and file

GSTR-9C

  • Excel and JSON import
  • Audit validations and portal comparison
  • JSON generation, filing and PDF download

Composition dealers: CMP-08 and GSTR-4

Quarterly payments and the yearly return for composition taxpayers.

CMP-08

  • Import from the portal or enter by hand
  • Interest, ledger check and challan creation
  • Payment, filing and a month-wise yearly report

GSTR-4

  • Prepare from Excel, JSON or by hand
  • Download and reconcile GSTR-4A
  • Payment and filing

Questions

Questions about TaxPower GST

Quick answers to what people ask first.

Does TaxPower GST run online or on my computer?

It is desktop software for Windows. You install it on your system and connect it to the GST portal through an authorised GSP when you want to download data or file.

Can I file returns without opening the GST portal?

Yes. You can upload and file with EVC/OTP or a DSC from inside the software. Portal data can also be downloaded for comparison before you file.

Can I bring in data from Tally or Excel?

Yes. TaxPower GST imports from Tally using Tally Connector, from Excel with your own column mapping, and from JSON files or other GST software.

I file for many clients. Is that supported?

Yes. A client dashboard shows the filing status of every client and period, with notes, reminders, user roles and password protection for client files.

Is billing part of the same software?

GST billing is a separate module that works with the returns module. Invoices you create can flow into your returns, so the same data is not entered twice.
