Before installation

Installation checklist

Please go through these points before you install.

  1. 1Check

    System

    Compare your Windows version, memory and disk space with the system requirements page.

  2. 2Backup

    Existing data

    When updating, first copy your current company data to a safe location.

  3. 3Download

    Setup file

    Choose the GST or TDS setup for which you hold a licence or trial, from the list above.

  4. 4Install

    Supporting packages

    Some versions need the database and runtime packages listed here. The installer indicates which are required.

  5. 5Contact

    If installation stops

    Note the error message and your licence ID and contact technical support.

Supporting downloads

Purpose of the additional downloads

A brief note on each supporting package listed on this page.

  • Database packages

    SQL Server Express and PostgreSQL are used to store company data on the computer.

  • Runtime packages

    .NET and Java runtimes are required by TaxPower and some of its utilities on Windows.

  • GST Signer

    A utility used with a digital signature certificate for signing returns.
